# Парсер данных акций с Yahoo Finance

Программа скачивает исторические данные об акциях, сохраняет в CSV и строит графики цен.

## Как запустить

1. Установи зависимости:
   pip install requests numpy matplotlib

2. Создай файл ticker_names.txt со списком тикеров:
   AAPL
   MSFT
   AMZN
   NVDA
   TSLA
   GOOGL
   META
   BRK-B
   UNH
   JPM

3. Запусти:
   python main.py

## Возможности

- Многопоточная загрузка данных
- Парсинг JSON от Yahoo Finance
- Сохранение в CSV
- Визуализация графиков

## Технологии

Python, requests, concurrent.futures, numpy, matplotlib
